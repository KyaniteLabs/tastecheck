# Repair handoffs

Read this after `INFERRED-SYSTEM.md` is approved and before assigning specialist
repairs. Use only the skills justified by observed defects; record a subject-absence
reason for every skipped specialist.

- `deslop-ui` removes generic/template tells without flattening established identity.
- `color-system` and `theming` consolidate semantic color roles and mappings.
- `web-typography` addresses scale, measure, wrapping, and font loading.
- `spacing-system` establishes a tokenized spacing scale and section rhythm tied to hierarchy.
- `responsive-layout` addresses structure, overflow, zoom, and hierarchy under reflow.
- `component-states` and `empty-states` cover interaction and non-happy paths where those
  subjects exist.
- `data-viz` applies only when charts or metrics are part of the surface.
- `art-direction` commits an imagery, illustration, and iconography system with source and rights.
- `a11y-pass` and `cognitive-a11y` verify accessible and cognitively usable repairs.
- `i18n-ready` verifies English/Spanish expansion, locale formatting, and bidi resilience.
- `humanize-copy` preserves facts while repairing generic or machine-written voice.
