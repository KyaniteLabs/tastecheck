what taste refuses

proof

This landing page is the integration surface.

The GitHub Pages homepage represents every skill concern directly and demonstrates named interactions: existing-site audit, inferred design system, OKLCH themes, type, states, form validation, empty/error/retry paths, chart/table parity, accessibility, human copy, motion, and responsive layout. The twentieth skill, tasteroll, is a procedural design generator — it audits what is broken, rolls committed design candidates from a seeded source of randomness, and locks the direction that works. A machine-only blind evaluation protocol (effectiveness v2) is built, rehearsed at 160 simulated calls with zero real calls, and adversarially tested — but production evaluation has not started.
