# Verge / Clinical evidence

**Territory:** cool, measured, evidence-led
**Signature:** measurement-annotated evidence cards; hypothesis → method → verdict reading order
**Type:** Fraunces (display) + Spline Sans (body) + DM Mono (annotations)
**Palette:** ice-white #f7f9fa · teal #0d7490 · graphite #1a2228

## Why this system exists

The v1.2 release added a machine-only blind evaluation protocol — a system that measures
whether the design skills actually improve outcomes. Verge is the visual embodiment of
that rigor: a clinical aesthetic where every element is annotated, measured, and placed
with evidence-led precision.

## What makes it different

- **First serif in the gallery** — Fraunces optical-sizing serif gives gravity and authority
- **Cool palette** — the only ice-white/teal system; every other light sample is warm
- **Measurement annotations** — specimen targets, ruler marks, vertical tags
- **Hypothesis → method → verdict** — the reading order mirrors the v2 evaluation protocol
- **Evidence cards** — skill cells have mono index labels and clinical spacing
