One page. Eight committed design systems.

Every sample below ships the same product story. The variable is the committed design system — so the difference you see is taste, not a new pitch.

That's the whole point of the interview: a real design system makes one product read as distinct products through structure, rhythm, type, color, and interaction. These eight don't share a section order or a skills layout — the spec-sheet leads with its index, the shipping log with a timeline, the bento demonstrates first. Not eight recolors of one skeleton. Run the repo verification gate and browser QA checklist before making release claims.
