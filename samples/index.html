One page. Five committed design systems.

Every sample below ships the exact same words and structure. The only variable is the design system — so the difference you see is taste, not content.

That's the whole point of the interview: a real design system makes identical content read as five distinct products — with five different layout grammars, not five recolors. Each one passes the same a11y audit (0 contrast fails, keyboard-navigable, reduced-motion safe) — opinionated and accessible aren't a tradeoff.
