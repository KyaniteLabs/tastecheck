---
description: Find and fix the accessibility barriers in a real user path
argument-hint: "[file/path or text, optional]"
---

Load and apply the **a11y-pass** skill (`~/.agents/skills/a11y-pass/SKILL.md`).

Walk the target like a user: keyboard and focus first, then names, semantics, contrast,
forms, live regions, targets, and zoom. Fix confirmed barriers as you find them. Return
the affected path, criterion, severity, repair, measurement, evidence, and provenance.
Automation supports the manual browser and screen-reader spot check; it does not replace it.

Target: $ARGUMENTS (if empty, apply to the current file / most recent work in context).

Run the skill's self-check before reporting what is fixed and what still blocks release.
