# Structural tells

Surface cleanup is not a structural repair. Inspect the page as a sequence of
sections and record the actual composition before proposing changes.

## High-signal attractors

- centered hero with one CTA followed by three equal feature cards;
- every section repeating the same eyebrow, heading, lede, grid rhythm;
- equal-weight cards where the brief calls for hierarchy or a narrative;
- full-viewport centering that hides content density and reading order;
- testimonial/stat bands inserted as decoration rather than product evidence.

## Repair method

1. Sketch the current section stack and mark repeated topology.
2. Compare it with the brief's information hierarchy and intended audience action.
3. Preserve useful content, then vary composition by meaning: lead story, list,
   split field, annotated detail, or deliberate pause.
4. Verify narrow layout and keyboard order after the structural change.

Report the original topology, the committed replacement, and the browser or source
evidence. A different number of cards without a different hierarchy is token-only
variation, not a structural repair.
