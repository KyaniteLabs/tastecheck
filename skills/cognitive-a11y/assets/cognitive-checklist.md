# Cognitive Accessibility — Ship Checklist
Run on any content or flow. Covers ADHD · autism · dyslexia · neurodivergence.

## Language (plain & literal)
- [ ] Sentences mostly ≤ ~20 words; one idea each
- [ ] Common words; jargon/acronyms defined or removed
- [ ] Literal — no idioms, metaphor, sarcasm, vague hedges
- [ ] Point front-loaded; active voice; ~grade-8 reading level

## Structure (chunk & summarize)
- [ ] Short paragraphs, headings, lists
- [ ] TL;DR / summary at top of long content
- [ ] One concept per chunk; progressive disclosure
- [ ] Multi-step tasks show steps + progress

## Predictability (autism)
- [ ] Consistent nav, labels, patterns; help in a consistent place
- [ ] Nothing auto-submits/advances/reflows on focus or input
- [ ] No autoplay; no surprising modals/carousels
- [ ] Expectations stated ("~3 min", "next: payment", "we'll email you")

## Memory & time (ADHD)
- [ ] No info must be recalled across screens (carry forward / show / autofill)
- [ ] One clear primary action per screen; fewest fields
- [ ] Progress saved; return loses nothing
- [ ] No time limits, or they're extendable/dismissible

## Sensory calm
- [ ] Calm default; motion subtle + user-stoppable; `prefers-reduced-motion` respected
- [ ] No flashing (>3/sec), no parallax/pulse overload
- [ ] No vibrating high-saturation color pairs; large fields low-chroma

## Reading (dyslexia)
- [ ] line-height ~1.5; measure 45–75ch; ragged-left (not justified); no long ALL-CAPS
- [ ] Off-white background + softened ink (not #fff/#000 glare), still ≥ WCAG minimums
- [ ] Real text (read-aloud/zoom friendly); icons paired with text; typo-tolerant inputs

## Errors & tone
- [ ] Errors say what's wrong + the fix, in plain words
- [ ] Destructive actions confirm + offer undo
- [ ] Empty/error tone is kind and non-judgmental

## Remember
Run **a11y-pass** too — it covers the technical/WCAG (sensory/motor/screen-reader) layer
this checklist does not.
