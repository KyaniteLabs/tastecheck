## Before touching anything
- [ ] Rendered the real site at 390 / 768 / 1280px (screenshots if possible)
- [ ] One full keyboard tab-through done
- [ ] De-facto tokens extracted WITH COUNTS (colors, type sizes, spacing, radii, shadows)
- [ ] Component habits inventoried (variants per component: decided or accidental?)
- [ ] Voice sampled (3 typifying quotes)
- [ ] Signal/drift split written, each line with its evidence
- [ ] "Likely system" stated in 5–8 bullets
- [ ] ≤3 questions asked — each one provably solution-changing (or "none needed" stated)
- [ ] Expected scope stated (rough % of visual surface to change)

## While editing
- [ ] WCAG-level defects (contrast/keyboard/reflow) fixed without asking
- [ ] Repeated choices converted to canonical semantic tokens, not one-off CSS
- [ ] Strongest identity signals preserved (or amplified), never sanitized away
- [ ] Brand-adjacent changes confirmed with the user first
- [ ] Scope still within what was stated — if exceeded, stopped and confirmed

## Before claiming done
- [ ] Re-rendered at 390 / 768 / 1280px; reflow + zoom hold
- [ ] Relevant skill self-checks run (component-states, form-ux, a11y-pass at minimum)
- [ ] Report written: signals preserved · drift removed · skills applied · verified
      how · deferred what
