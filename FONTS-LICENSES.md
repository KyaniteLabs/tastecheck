# Bundled font licenses

The repo's MIT license covers the skills, tools, and site code — **not** the bundled
font binaries, which keep their own licenses:

| Files | Typeface | License |
|---|---|---|
| `samples/fonts/hanken-{400,600,800}.woff2` | Hanken Grotesk | SIL Open Font License 1.1 (via Google Fonts) |
| `samples/fonts/bricolage-{700,800}.woff2` | Bricolage Grotesque | SIL Open Font License 1.1 (via Google Fonts) |
| `site/fonts/redaction-70-700.woff2` | Redaction (Titus Kaphar & Forest Young / MCKL) | Distributed free at redaction.us — re-verify its terms before redistributing further; if redistribution is ever a concern, swap for an OFL face |

The OFL permits bundling and redistribution with the license intact; the canonical OFL
text is at <https://openfontlicense.org>. If you fork this repo and ship the fonts,
these obligations travel with them.
